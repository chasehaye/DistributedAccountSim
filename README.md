These directories explore the core concepts in distributed systems by implementing and extending a replicated banking system using gRPC. Starting from a baseline model where multiple branches maintain consistent replicas of a shared account, each project incrementally introduces different consistency mechanisms. The Lamport logical clock implementation demonstrates how event ordering can be preserved across distributed processes without a global clock. Building on this foundation, the client-centric consistency projects enforce guarantees such as Read Your Writes consistency and Monotonic Writes consistency, ensuring that individual clients observe a logically consistent view of their own operations across replicas. Together, these implementations highlight how different consistency models can be layered onto a distributed system to balance correctness, usability, and system design constraints.

Across these implementations, key principles of consistent distributed systems are explored, including maintaining a well-defined ordering of events, ensuring visibility of updates across replicas, preserving causality between operations, and coordinating state across independent nodes without centralized control. Together, these projects highlight how different consistency models can be layered onto a distributed system to balance and select trade offs for the system.
